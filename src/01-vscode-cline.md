## Что такое Cline и зачем он нужен

**Cline** — это ИИ-агент, который работает прямо внутри редактора VS Code. В отличие от обычных
автодополнений, он умеет:

- читать файлы проекта и объяснять, как он устроен;
- создавать и редактировать код (каждое изменение показывается в виде diff);
- запускать команды в терминале и смотреть на их вывод;
- искать ошибки, открывать страницу в браузере и проверять результат;
- подключать дополнительные инструменты через MCP.

Главный принцип Cline — **human-in-the-loop**: агент предлагает действие, а вы подтверждаете его
кнопкой. Пока вы не разрешили, файл не изменится и команда не выполнится.

> 💡 **Кому подойдёт:** новичкам, которые учатся программировать, и опытным разработчикам, которым
> нужно быстро разобраться в чужом проекте или автоматизировать рутину.

## Что понадобится

| Компонент | Требование |
|---|---|
| Редактор | VS Code актуальной версии (желательно 1.93+) |
| Операционная система | Windows 10/11, macOS 12+, современный Linux |
| Интернет | Нужен для облачной модели; локальная модель может работать офлайн |
| Аккаунт провайдера | Cline Provider, OpenRouter, Anthropic, OpenAI, Google и др. |
| Свободное место | От 300 МБ для редактора и расширений |

Для комфортной работы желательно **8 ГБ ОЗУ и больше**. Модель работает в облаке, поэтому мощная
видеокарта не нужна — только стабильный интернет.

## Шаг 1. Установите VS Code

### Windows

**Способ 1 — через winget (рекомендуется).** Откройте PowerShell и выполните:

```powershell
winget install --id Microsoft.VisualStudioCode -e
```

**Способ 2 — установщик.** Скачайте файл с официального сайта
[code.visualstudio.com/download](https://code.visualstudio.com/download), запустите его и оставьте
галочки «Add to PATH» и «Register Code as an editor for supported file types».

### macOS

Скачайте архив с [code.visualstudio.com/download](https://code.visualstudio.com/download),
распакуйте и перетащите **Visual Studio Code.app** в папку «Программы». Если установлен Homebrew:

```bash
brew install --cask visual-studio-code
```

Чтобы открывать редактор командой `code` из терминала, выполните в VS Code:
`Command Palette (⇧⌘P)` → **Shell Command: Install 'code' command in PATH**.

### Linux

Скачайте `.deb` или `.rpm` с официального сайта и установите:

```bash
sudo apt install ./code_*.deb      # Debian/Ubuntu
sudo dnf install ./code-*.rpm      # Fedora
```

Либо используйте snap:

```bash
sudo snap install code --classic
```

### Проверка

Откройте VS Code. В меню **Help → About** (на Windows/Linux) или **Code → About Visual Studio Code**
(macOS) должна отображаться версия редактора. Если вы добавили `code` в PATH, проверьте терминал:

```bash
code --version
```

> ⚠️ Если команда `code` не найдена, это не критично: дальше можно работать полностью через
> графический интерфейс.

## Шаг 2. Установите расширение Cline

### Через интерфейс

1. Откройте панель расширений: `Ctrl+Shift+X` (Windows/Linux) или `⇧⌘X` (macOS).
2. Введите в поиске **Cline**.
3. Найдите расширение от издателя **Cline** (страница
   [marketplace.visualstudio.com](https://marketplace.visualstudio.com/items?itemName=saoudrizwan.claude-dev)).
4. Нажмите **Install** и дождитесь окончания установки.
5. Нажмите на иконку Cline на боковой панели (или `Ctrl+Shift+P` → **Cline: Open**).

### Через командную строку

Если `code` доступен в PATH:

```bash
code --install-extension saoudrizwan.claude-dev
```

### Первый запуск

При первом открытии Cline попросит выбрать способ доступа к модели. Не закрывайте панель — на
следующем шаге мы её настроим.

> 💡 Удобно перенести Cline в правую боковую панель: так код и чат видны одновременно.

## Шаг 3. Подключите модель

Cline — это «мозг без знаний»: сам по себе он не умеет думать, ему нужна языковая модель. Начните с
бесплатного варианта, а платные подключения оставьте на потом — они пригодятся, когда упрётесь в
лимиты.

### Бесплатные варианты

Платить за модель не обязательно. Вот рабочие способы начать без подписки:

| Вариант | Что бесплатно | Ограничения |
|---|---|---|
| **Бесплатные модели Cline Provider** | Отдельные модели доступны без оплаты после входа в аккаунт Cline | Список моделей и лимиты меняются; обычно это модели поменьше |
| **OpenRouter `:free`** | Модели с суффиксом `:free` в названии | Общий суточный лимит и очередь; часть моделей недоступна в России |
| **Google AI Studio** | Бесплатный тариф Gemini API для обучения | Лимиты запросов; **в России официально недоступен** |
| **Ollama / LM Studio** | Полностью бесплатно после установки | Нужны 8–16 ГБ ОЗУ; модель слабее облачной, но данные не уходят в интернет |

Как подключить бесплатную модель:

1. **Cline Provider:** настройки → **API Provider** → **Cline** → войдите в аккаунт и выберите модель с
   пометкой «free».
2. **OpenRouter:** создайте ключ на [openrouter.ai](https://openrouter.ai), в Cline выберите
   **OpenRouter**, нажмите **Refresh Models** и найдите модель, в названии которой есть `:free`.
3. **Google Gemini:** получите ключ в AI Studio, выберите в Cline провайдера **Google Gemini** и
   вставьте ключ. Этот вариант доступен не во всех странах (в России — нет); тогда используйте
   Ollama или OpenRouter.
4. **Локально:** установите Ollama, выполните `ollama pull qwen2.5-coder:7b`, выберите в Cline
   провайдера **Ollama** и модель из списка.

#### Локальная модель: подробнее

Полностью бесплатный и независимый от региона вариант — запуск модели на своём компьютере:

1. Установите [Ollama](https://ollama.com).
2. Скачайте модель, например:

   ```bash
   ollama pull qwen2.5-coder:7b
   ```

3. В Cline выберите провайдера **Ollama** (или **LM Studio**).
4. Укажите адрес локального сервера: обычно `http://localhost:11434`.
5. Выберите загруженную модель.

Локальные модели слабее облачных и требуют 8–16 ГБ ОЗУ, зато данные не покидают компьютер.

> ⚠️ У бесплатных тарифов есть лимиты и очередь, а условия могут меняться. Для первых опытов этого
> достаточно; для регулярной работы над большим проектом подойдёт платная модель или локальный
> запуск.

### Платные варианты

Когда бесплатных лимитов перестаёт хватать, можно подключить платный доступ.

#### Cline Provider или ClinePass

1. В настройках Cline выберите **Cline Provider**.
2. Войдите в аккаунт Cline и оплатите использование по факту (pay-as-you-go) либо подключите
   подписку **ClinePass** с фиксированной ценой.
3. Выберите модель из списка.

Плюсы: не нужно заводить отдельный аккаунт у провайдера. Минусы: оплата и лимиты зависят от Cline.

#### Свой ключ (BYOK) через OpenRouter

**OpenRouter** — агрегатор, через который одним ключом доступны десятки моделей разных компаний.
Это удобно для учёбы: можно сравнить модели и выбрать недорогую.

1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai).
2. Откройте раздел **Keys** → **Create Key**.
3. Скопируйте ключ вида `sk-or-v1-...` и сохраните его в надёжном месте.
4. Пополните баланс и выберите платную модель.

В Cline:

1. Нажмите на шестерёнку → **API Configuration**.
2. **API Provider** → **OpenRouter**.
3. Вставьте ключ в поле **OpenRouter API Key**.
4. Нажмите **Refresh Models** и выберите модель.
5. Сохраните настройки.

> 🔐 Ключ — это пароль от вашего кошелька. Не вставляйте его в чат с моделью, не публикуйте в
> GitHub и не сохраняйте в файлах проекта.

### Как выбрать модель

| Задача | Что выбрать |
|---|---|
| Учёба, простые правки | недорогая быстрая модель |
| Сложный рефакторинг, большой проект | сильная модель с большим контекстом |
| Работа без интернета | локальная модель через Ollama |
| Первый запуск | бесплатная модель, чтобы проверить настройку |

## ⚠️ Модели и сервисы, недоступные в России

Это важно проверить **до** регистрации и оплаты: часть провайдеров официально не работает в РФ, а
доступность бесплатных моделей зависит от страны.

| Сервис или модель | Доступность в России | Чем заменить |
|---|---|---|
| **Google Gemini API / AI Studio** | Официально не предоставляется | локальная модель через Ollama/LM Studio |
| **OpenAI API (модели GPT)** | Официально не предоставляется | локальная модель или провайдер, работающий в вашем регионе |
| **Anthropic API (модели Claude)** | Официально не предоставляется | локальная модель или провайдер, работающий в вашем регионе |
| **OpenRouter `:free`** | Зависит от конкретной модели и её провайдера: часть моделей недоступна | модели, доступные в регионе, или Ollama |
| **Ollama / LM Studio** | ✅ Доступны: работают локально, без привязки к стране | — |

## Шаг 4. Первый проект

### Создайте папку

Например, `C:\projects\cline-start` (Windows) или `~/projects/cline-start` (macOS/Linux).
В VS Code: **File → Open Folder** и выберите эту папку.

> ⚠️ Открывайте именно папку проекта, а не отдельный файл: агенту нужен доступ к рабочей области.

### Создайте стартовый файл

Создайте `index.html` с минимальной заготовкой:

```html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <title>Мой первый проект</title>
</head>
<body>
  <h1>Привет!</h1>
</body>
</html>
```

### Сформулируйте задачу

Откройте Cline и напишите запрос. Чем конкретнее задача, тем лучше результат:

```text
Открой index.html и добавь на страницу:
1) заголовок «Мой первый проект с ИИ»;
2) кнопку «Показать факт»;
3) при нажатии на кнопку показывай случайный факт об информатике
   из массива в отдельном файле script.js.

Стили вынеси в style.css: светлая тема, крупный шрифт, отступы.
Сначала предложи план, ничего не меняй без моего подтверждения.
```

### Примите изменения

1. Cline покажет план — прочитайте его и при необходимости уточните.
2. Переключитесь в режим **Act** (или подтвердите переход) и разрешите правки.
3. Для каждого файла откроется diff: проверьте изменения и нажмите **Approve**.
4. Если агент просит выполнить команду — прочитайте её и подтвердите запуск.
5. Откройте `index.html` в браузере и проверьте результат.

> 💡 Если результат не понравился, используйте **Checkpoints**: верните рабочую область к состоянию
> до шага агента и попросите переделать.

## Как устроена работа с агентом

| Режим | Что делает |
|---|---|
| **Plan** | Только читает файлы и предлагает план, ничего не меняя |
| **Act** | Выполняет план: правит файлы, запускает команды |
| **Checkpoints** | Снимки состояния проекта, к которым можно откатиться |

Полезные возможности ввода:

- `@file` — добавить файл в контекст;
- `@folder` — добавить папку целиком;
- `@url` — передать содержимое веб-страницы;
- `@problems` — передать ошибки из панели Problems.

## Безопасность и экономия

1. **Не включайте Auto-approve** на первых порах. Подтверждайте каждое действие вручную.
2. **Читайте diff перед Approve.** Агент может изменить больше, чем вы просили.
3. **Не давайте доступ к секретам.** Ключи и пароли держите в `.env`, а `.env` добавьте в
   `.gitignore`. Создайте `.clineignore` для файлов, которые агент не должен читать.
4. **Коммитьте перед экспериментами.** Git — лучшая страховка: `git add . && git commit -m "before AI"`.
5. **Следите за расходом.** Cline показывает токены и стоимость задачи. Для простых действий
   выбирайте дешёвую модель.
6. **Проверяйте код.** Агент может ошибаться: запускайте проект и тесты самостоятельно.

Пример `.clineignore`:

```text
.env
node_modules/
dist/
*.key
```

## Полезные настройки

### Правила проекта `.clinerules`

Создайте в корне проекта файл `.clinerules` — Cline будет учитывать его в каждой задаче:

```text
- Пиши комментарии и интерфейс на русском языке.
- Не используй фреймворки без явной просьбы.
- Все новые файлы создавай в папке src/.
- Перед изменением файла объясни план.
```

### MCP-серверы

MCP (Model Context Protocol) позволяет подключить к агенту внешние инструменты: базы данных,
GitHub, браузер, файловую систему. Начинать стоит с готовых серверов, а не писать свой.

### Горячие клавиши

| Действие | Windows/Linux | macOS |
|---|---|---|
| Открыть панель Cline | иконка Cline | иконка Cline |
| Палитра команд | `Ctrl+Shift+P` | `⇧⌘P` |
| Терминал | `Ctrl+`` | `` Ctrl+` `` |
| Поиск по файлам | `Ctrl+P` | `⌘P` |

## Типичные проблемы

| Проблема | Причина | Решение |
|---|---|---|
| Не вижу иконку Cline | Панель скрыта | `Ctrl+Shift+P` → **Cline: Open**, затем перезагрузите окно |
| `code: command not found` | VS Code не добавлен в PATH | macOS: **Shell Command: Install 'code' command in PATH**; Windows: переустановите с галочкой «Add to PATH» |
| Ошибка 401 | Неверный или отозванный ключ | Создайте новый ключ и вставьте его заново |
| Ошибка 429 | Лимит запросов | Подождите, смените модель или провайдера |
| Модель отвечает «недостаточно средств» | Закончился баланс | Пополните счёт или выберите бесплатную модель |
| Агент не запускает команды | Нет интеграции терминала | Обновите VS Code и проверьте настройки терминала |
| Ответы обрезаны | Мало контекстное окно | Выберите модель с большим контекстом или сократите задачу |

## Проверьте себя

1. Зачем Cline нужен API-ключ, если он уже установлен в VS Code?
2. Чем режим **Plan** отличается от режима **Act**?
3. Почему нельзя сохранять API-ключ в файле проекта?
4. Что произойдёт, если нажать **Approve** на diff, не прочитав его?
5. Как откатить изменения, которые агент сделал несколько шагов назад?
6. Назовите два бесплатных способа поработать с Cline без оплаты API.

<details>
<summary>Ответы</summary>

1. Cline — это интерфейс агента, а «думает» языковая модель у провайдера. Ключ подтверждает, что
   запросы к модели оплачиваются вашим аккаунтом.
2. Plan только анализирует и предлагает план, Act — выполняет действия и меняет файлы.
3. Ключ даёт доступ к платному аккаунту. Файл может попасть в Git или в чужие руки.
4. Изменения будут применены к проекту, даже если они лишние или ломают код.
5. Через **Checkpoints**: выбрать нужный снимок и восстановить рабочую область.
6. Например, бесплатные модели Cline Provider, модели OpenRouter с пометкой `:free`, бесплатный
   тариф Google AI Studio или локальная модель через Ollama/LM Studio.

</details>
