## Что такое opencode

**opencode** — открытый ИИ-агент для терминала. Вы запускаете его в папке проекта и общаетесь с ним
обычным текстом: он читает файлы, ищет по коду, вносит правки и выполняет команды. Работает не в
браузере, а прямо там, где вы запускаете сборку и тесты.

Чем он отличается от Cline из предыдущего урока:

| | Cline | opencode |
|---|---|---|
| Где работает | внутри VS Code | в терминале (TUI) |
| Интерфейс | панель с кнопками | текстовый интерфейс |
| Подходит для | наглядной работы с файлами | серверов, скриптов, SSH |
| Настройка | через графические настройки | через конфиг и команды |

Оба инструмента могут работать с одним и тем же проектом — выбирайте тот, который удобнее в
конкретной ситуации.

## Что понадобится

| Компонент | Требование |
|---|---|
| Node.js | LTS-версия, не ниже 20 (рекомендуется 22+) |
| npm | Устанавливается вместе с Node.js |
| Терминал | Windows Terminal, PowerShell 7, Terminal.app, GNOME Terminal и др. |
| Аккаунт провайдера | OpenRouter, Anthropic, OpenAI, Google или локальная модель |
| Интернет | Для облачной модели; локальная может работать офлайн |

> 💡 На Windows opencode работает и напрямую, но авторы рекомендуют **WSL** (Windows Subsystem for
> Linux) — там меньше проблем с путями, терминалом и правами.

## Шаг 1. Установите Node.js

Node.js нужен, чтобы запускать npm-пакеты и сам opencode.

### Windows

**Способ 1 — winget (рекомендуется).** Откройте PowerShell:

```powershell
winget install --id OpenJS.NodeJS.LTS -e
```

**Способ 2 — установщик.** Скачайте LTS-версию с [nodejs.org](https://nodejs.org), запустите `.msi`
и оставьте галочку **Add to PATH**.

**Способ 3 — nvm-windows.** Удобно, если нужно переключать версии Node.js:
установите [nvm-windows](https://github.com/coreybutler/nvm-windows), затем:

```powershell
nvm install lts
nvm use lts
```

### macOS

Скачайте `.pkg` с [nodejs.org](https://nodejs.org) или используйте Homebrew:

```bash
brew install node
```

### Linux

```bash
# Debian/Ubuntu — через NodeSource (пример для LTS-ветки 22)
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
```

Либо через nvm:

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
nvm install --lts
nvm use --lts
```

### Проверка

Закройте и снова откройте терминал, затем выполните:

```bash
node --version
npm --version
```

Должны появиться номера версий, например `v22.x.x` и `10.x.x`. Если команды не найдены — Node.js не
попал в PATH; переустановите его с галочкой «Add to PATH» или добавьте каталог вручную.

> ⚠️ Если версия Node.js ниже 20, обновитесь: старые версии не поддерживаются современными
> пакетами.

## Шаг 2. Установите opencode

### Основной способ — npm

```bash
npm install -g opencode-ai
```

Флаг `-g` означает глобальную установку: команда `opencode` станет доступна в любом каталоге.

### Альтернативные способы

**Скрипт установки (macOS/Linux):**

```bash
curl -fsSL https://opencode.ai/install | bash
```

**Homebrew (macOS/Linux):**

```bash
brew install anomalyco/tap/opencode
```

**Windows (Chocolatey или Scoop):**

```powershell
choco install opencode
# или
scoop install opencode
```

**Docker:**

```bash
docker run -it --rm ghcr.io/anomalyco/opencode
```

### Проверка

```bash
opencode --version
```

Если команда не найдена:

1. Закройте и откройте терминал заново.
2. Проверьте глобальный каталог npm:

   ```bash
   npm config get prefix
   ```

3. Убедитесь, что он есть в PATH. На Windows обычно это
   `C:\Users\<имя>\AppData\Roaming\npm`.

> 📌 В 2026 году существуют две ветки проекта — OpenCode 1 и OpenCode 2. Они используют одну команду
> `opencode` и не ставятся одновременно. Пакет `opencode-ai` из npm соответствует OpenCode 1;
> инструкции для второй версии смотрите на [opencode.ai/v2/docs](https://opencode.ai/v2/docs/).

## Шаг 3. Подключите модель

Без модели opencode не сможет отвечать. Есть два способа передать ключ.

### Способ A. Команда `/connect` (рекомендуется)

1. Перейдите в папку проекта и запустите агент:

   ```bash
   cd C:\projects\my-project
   opencode
   ```

2. В открывшемся интерфейсе введите:

   ```text
   /connect
   ```

3. Выберите провайдера. Для быстрого старта можно выбрать **opencode** — он предложит ссылку на
   [opencode.ai/auth](https://opencode.ai/auth), где нужно войти, пополнить баланс и скопировать ключ.
4. Вставьте ключ в поле ввода и нажмите Enter.
5. Проверьте список доступных моделей командой `/models` и выберите подходящую.

Можно подключить и других провайдеров: OpenRouter, Anthropic, OpenAI, Google. Принцип тот же:
выбрать провайдера и вставить ключ.

### Способ B. Переменные окружения

Некоторые провайдеры читают ключ из переменной окружения, например:

```bash
# macOS/Linux
export OPENROUTER_API_KEY="sk-or-v1-..."
export ANTHROPIC_API_KEY="sk-ant-..."

# Windows PowerShell
$env:OPENROUTER_API_KEY = "sk-or-v1-..."
```

Чтобы переменная сохранялась между запусками, добавьте её в профиль терминала или в системные
переменные Windows.

> 🔐 Не храните ключи в `opencode.json`, который лежит в Git. Используйте переменные окружения или
> отдельный файл, добавленный в `.gitignore`.

### Выбор модели

Модель задаётся в формате `провайдер/модель`, например `anthropic/claude-sonnet-5-5`. Актуальные
идентификаторы смотрите в `/models` — они меняются чаще, чем выходят новые версии сайта.

Для учёбы:

- быстрая и дешёвая модель — для объяснений и мелких правок;
- сильная модель с большим контекстом — для рефакторинга и больших проектов;
- локальная модель через Ollama — если нужна работа без облака.

### Бесплатные варианты

Начать можно без платной подписки:

| Вариант | Что бесплатно | Ограничения |
|---|---|---|
| **Бесплатные модели OpenCode Go** | Отдельные модели (например, Beam Free и Iceman Contributor Free) | Временная акция, ограниченные регионы; Beam Free недоступна в России |
| **OpenRouter `:free`** | Модели с суффиксом `:free` | Суточный лимит и очередь; часть моделей недоступна в России |
| **Google AI Studio** | Бесплатный тариф Gemini API | Лимиты запросов; **в России официально недоступен** |
| **Ollama / LM Studio** | Полностью бесплатно локально | Нужны 8–16 ГБ ОЗУ, модель слабее облачной |

Как подключить бесплатный вариант:

1. **OpenRouter:** получите ключ на [openrouter.ai](https://openrouter.ai), выполните `/connect`,
   выберите OpenRouter и вставьте ключ. Затем `/models` и выберите модель с `:free`.
2. **Google Gemini:** получите ключ в [aistudio.google.com](https://aistudio.google.com), подключите
   провайдера через `/connect` и выберите модель. В России сервис официально недоступен — используйте
   Ollama или OpenRouter.
3. **Локально:** установите [Ollama](https://ollama.com), выполните `ollama pull qwen2.5-coder:7b`,
   подключите провайдера Ollama и выберите модель.

> ⚠️ Бесплатные тарифы меняются: лимиты, список моделей и доступность по регионам могут отличаться.
> Проверяйте актуальные условия у провайдера.

## OpenCode Go

**OpenCode Go** — это необязательная подписка от команды OpenCode: она даёт стабильный доступ к
популярным моделям для кода по фиксированной цене. Обычный opencode работает и без неё — Go нужен,
если вы хотите предсказуемые лимиты и не хотите отдельно регистрироваться у каждого провайдера.

### Тарифы

| План | Цена | Что входит |
|---|---|---|
| **Go** | $10 в месяц | Доступ к моделям Go с базовыми лимитами |
| **Go Plus** | $40 в месяц | Те же модели с повышенными лимитами |
| **Go Teams** | $20 за участника в месяц | Отдельные лимиты каждому участнику команды |

Цены и состав моделей могут меняться — сверяйтесь с
[opencode.ai/v2/docs/console/go](https://opencode.ai/v2/docs/console/go).

### Как подключить

1. Войдите в [OpenCode Console](https://opencode.ai/console) и оформите подписку Go, Go Plus или
   Go Teams.
2. Скопируйте API-ключ.
3. Запустите opencode в проекте и выполните:

   ```text
   /connect
   ```

4. Выберите **OpenCode Go** и вставьте ключ.
5. Выполните `/models` и выберите модель.

В конфиге модель Go записывается с префиксом `opencode-go/`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "opencode-go/kimi-k3"
}
```

Идентификатор модели берите из `/models` — список обновляется.

### Бесплатные модели в Go

В подписке Go есть и бесплатные модели, например **Beam Free** и **Iceman Contributor Free**. Это
временные предложения:

- **Beam Free** доступна ограниченное время и не работает в ряде регионов, включая Россию;
- **Iceman Contributor Free** доступна ограниченное время;
- после исчерпания лимитов Go можно продолжать пользоваться бесплатными моделями.

Подробный список ограничений по России — в блоке
[«Модели и сервисы, недоступные в России»](#модели-и-сервисы-недоступные-в-россии) выше.

Если бесплатная модель недоступна в вашем регионе, используйте OpenRouter `:free` (модели, доступные
в регионе) или локальную модель через Ollama.

## Шаг 4. Первый запуск в проекте

### Откройте проект

```bash
cd ~/projects/my-project
opencode
```

opencode смотрит на текущую папку и ближайший Git-репозиторий. Поэтому запускайте его именно из
корня проекта, а не из домашнего каталога.

### Создайте `AGENTS.md`

Внутри интерфейса выполните:

```text
/init
```

Агент проанализирует структуру проекта и создаст файл `AGENTS.md` с описанием правил и команд.
Этот файл стоит закоммитить в Git: так агент будет понимать проект при следующих запусках.

### Спросите о проекте

```text
Объясни, как устроен этот проект: какие основные файлы,
как запускается сборка и где лежит логика авторизации.
```

Чтобы добавить файл в контекст, начните ввод с `@` и выберите файл через нечёткий поиск:

```text
Как работает функция parseConfig в @src/config.js?
```

### Попросите изменить код

Сначала полезно поработать в режиме планирования. Переключение — клавиша **Tab**:

1. Нажмите **Tab** — включится **Plan mode** (агент только предлагает план).
2. Опишите задачу:

   ```text
   Добавь в проект страницу «О нас»: новый маршрут /about,
   шаблон с заголовком и текстом, ссылку в меню.
   Сначала покажи план, ничего не меняй.
   ```

3. Обсудите и уточните план.
4. Нажмите **Tab** ещё раз — вернётесь в **Build mode**.
5. Попросите выполнить план. Агент покажет изменения; подтверждайте их.

### Отмена и повтор

- `/undo` — отменить последнее изменение и вернуть исходный запрос;
- `/redo` — повторить отменённое;
- `/undo` можно вызывать несколько раз подряд.

## Настройка через `opencode.json`

Конфиг можно положить в корень проекта (тогда он действует только на него) или в глобальный каталог
`~/.config/opencode/opencode.json` (на Windows — `%USERPROFILE%\.config\opencode\opencode.json`).

Пример безопасного проекта:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "anthropic/claude-sonnet-5-5",
  "permission": {
    "edit": "ask",
    "bash": "ask"
  }
}
```

Что здесь важно:

- `model` — модель по умолчанию; замените на ID из `/models`;
- `permission.edit: "ask"` — спрашивать подтверждение перед каждой правкой файла;
- `permission.bash: "ask"` — спрашивать перед каждой командой терминала.

По умолчанию opencode разрешает большинство операций без подтверждения (кроме чтения `.env` и
доступа за пределы проекта). Для учебного проекта безопаснее включить `ask`.

Другие полезные поля:

| Поле | Назначение |
|---|---|
| `small_model` | дешёвая модель для служебных задач |
| `instructions` | список файлов с правилами, например `["AGENTS.md"]` |
| `mcp` | подключение MCP-серверов |
| `formatter` | автоформатирование изменённых файлов |
| `autoupdate` | проверка обновлений opencode |

## Расширяемость

- **Правила** — `AGENTS.md` в корне проекта: стиль кода, запреты, команды сборки.
- **Команды** — файлы в `.opencode/commands/`: например, `/test` для запуска тестов.
- **Агенты** — отдельные роли в `.opencode/agents/`: ревьюер, автор тестов, документалист.
- **Skills** — переиспользуемые инструкции для типовых задач.
- **MCP-серверы** — внешние инструменты: GitHub, базы данных, браузер.
- **Плагины** — расширения на JavaScript/TypeScript.

Начинать стоит с `AGENTS.md` и нескольких команд — этого хватает большинству учебных проектов.

## Безопасность

1. **Подтверждайте команды.** Особенно `rm`, `git push`, `npm publish`, обращения к базе данных.
2. **Читайте diff.** Агент может затронуть больше файлов, чем вы ожидали.
3. **Коммитьте до эксперимента.** `git add . && git commit -m "before AI"` — и откат всегда под рукой.
4. **Ограничьте права.** `permission.bash: "ask"` и `permission.edit: "ask"` сильно снижают риск.
5. **Не давайте доступ к секретам.** Ключи — в переменных окружения, `.env` — в `.gitignore`.
6. **Проверяйте результат.** Запустите проект и тесты сами, не полагайтесь только на отчёт агента.

## Типичные проблемы

| Проблема | Причина | Решение |
|---|---|---|
| `opencode: command not found` | Глобальный каталог npm не в PATH | Добавьте `npm config get prefix` в PATH и перезапустите терминал |
| `npm install -g` падает с `EACCES` (macOS/Linux) | Нет прав на системный каталог | Используйте nvm или настройте пользовательский prefix |
| `npm` не работает в PowerShell | Политика выполнения скриптов | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| `node --version` показывает старую версию | В PATH другой Node.js | Переустановите LTS или переключитесь через nvm |
| Ошибка 401 при запросе к модели | Ключ неверный или не подключён | Повторите `/connect`, проверьте ключ у провайдера |
| Ошибка 429 | Лимит запросов | Смените модель или подождите |
| Терминал «плывёт» на Windows | Ограничения стандартной консоли | Используйте Windows Terminal или WSL |
| Нет доступа к интернету из-за прокси | Корпоративная сеть | Задайте `HTTPS_PROXY` и `HTTP_PROXY` в переменных окружения |
