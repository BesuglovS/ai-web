# Шаблон урока — курс для 10–11 классов

Руководство по написанию и перепроектированию уроков курса «AI — Основы искусственного интеллекта»
под аудиторию **учеников 10–11 классов российской школы (16–18 лет)**.

Метаданные урока (номер, слаг, длительность, сложность, секция) живут в `lessons.json` — источнике
истины. Этот документ описывает **содержание и стиль** самого файла `src/NN-slug.md`.

---

## 1. Аудитория и принципы

Кто наш читатель: старшеклассник, который пользуется смартфоном и чат-ботами, знает математику
на уровне 10–11 классов (или изучает её параллельно), но почти не писал серьёзного кода.

Принципы:

1. **От жизни — к теории.** Каждый урок открывается ситуацией из мира подростка (лента рекомендаций,
   автодополнение в клавиатуре, генерация картинок), и только потом вводит термин.
2. **Одна аналогия на одну концепцию.** Аналогия объясняет интуицию; сразу после неё даётся точное
   определение или формула.
3. **Математика — опора на школьную программу.** Векторы → геометрия 9–11 кл., производная → алгебра
   11 кл., вероятности → задачи ЕГЭ. Новая математика вводится пошагово с расшифровкой каждого символа.
4. **Практика на каждом уроке.** Задание выполняется на веб-инструментах (GigaChat, Алиса,
   YandexGPT, ChatGPT) без установки чего-либо; для раздела «Инструменты разработчика» и заданий
   «со звёздочкой» допускаются агентные системы (Opencode, Cline) и локальные модели (Ollama).
5. **Честность про границы.** Говорим, чего ИИ не умеет, откуда берутся ошибки и предвзятость;
   обсуждаем этику и академическую честность (когда использовать чат-бот для домашки допустимо).
6. **Микроформат.** Урок читается за 8–15 минут: 600–1200 слов основного текста.
7. **Русские сервисы рядом с глобальными.** Примеры даём парами: GigaChat/Алиса/YandexGPT и
   ChatGPT/Gemini — доступность инструментов у аудитории разная.

## 2. Front matter (обязательные поля)

```yaml
---
layout: layout.njk
title: "..."                  # совпадает с lessons.json
description: "..."            # совпадает с lessons.json, ≤ 160 знаков
lessonNumber: 2               # совпадает с lessons.json
lessonSlug: "02-course-overview"  # совпадает с именем файла NN-slug.md
lessonComplexity: beginner    # beginner | basic | intermediate | advanced
lessonDuration: 8             # целое, минуты чтения
lessonSection: intro          # id секции из lessons.json
---
```

Имя файла строго `NN-slug.md` (две цифры + дефис). Слаг менять нельзя — на нём завязаны URL,
квизы и навигация.

## 3. Структура урока

```markdown
## <Тема урока: цепляющий вопрос или ситуация>

Хук: 1–2 абзаца из жизни подростка, подводящие к теме.
Далее — основной теоретический материал: 2–4 подраздела `###`.

### <Подраздел 1>
### <Подраздел 2>

## Практика

Пошаговое задание (см. §4). Шаги нумеруем, результат — конкретный артефакт
(таблица сравнения, скриншот, ответ, вывод одним предложением).

## Связь со школьной программой        <!-- необязательно вне раздела math -->

2–4 пункта: где тема пересекается с информатикой, математикой, физикой,
обществознанием или ЕГЭ/олимпиадами.

## Проверьте себя

1–3 открытых вопроса по материалу урока (не «да/нет»). Ответы должны
проверяться текстом урока.

## Дополнительные ресурсы

2–4 ссылки. Только проверенные URL. Приветствуются русскоязычные материалы.
```

Правила заголовков:

- Первый `##` после front matter — вход в тему (хук), его текст формулируем как вопрос или интригующее
  утверждение («Почему лента знает тебя лучше друзей?»).
- Заголовок `## Проверьте себя` обязателен и пишется ровно так (по нему ориентируются модули сайта).
- Не дублировать название урока в первом `##`.

## 4. Форматы практики

| Тип | Когда | Инструменты | Требования |
|---|---|---|---|
| **Веб-эксперимент** | Большинство уроков | GigaChat, Алиса, YandexGPT, ChatGPT, Gemini | Без регистрации/установки где возможно; шаги воспроизводимы |
| **Наблюдение** | История, оценка моделей | Телефон, карты, переводчик, рекомендательные ленты | Ученик фиксирует наблюдение письменно (таблица/вывод) |
| **Агентная работа** | Разделы llama/tools и задания «со звёздочкой» | Opencode, Cline, Ollama | Явно помечать «со звёздочкой», если нужен свой компьютер |

Требования к любому практическому блоку:

- есть измеримый результат (что именно ученик должен получить);
- есть вопрос для осмысления («Что в ответе бота указывает на то, что это узкий ИИ?»);
- время выполнения ≤ 15 минут;
- не требуется установка ПО, кроме явно помеченных заданий.

## 5. Стиль текста

- Обращение — на «ты», глаголы — в настоящем времени и повелительном наклонении («посмотри»,
  «сравни»), без фамильярности и сленга.
- Предложения до ~20 слов. Абзацы до 4 предложений.
- Каждый список — с содержательным началом: «ИИ уже сегодня умеет:», а не просто «примеры:».
- Термины: при первом упоминании — русский перевод + английский оригинал в скобках:
  «механизм внимания (self-attention)». Дальше можно использовать одно обозначение.
- Формулы: не более одной на подраздел, каждая расшифровывается словами и поясняется на числах.
- Код появляется только в практиках llama/tools разделов; комментарии в коде — по-русски.
- Числа и факты: год, имя, одна цифра работают лучше трёх прилагательных. Проверяй факты.

## 6. Чек-лист автора

- [ ] Front matter совпадает с записью в `lessons.json` (title, description, number, slug,
      complexity, duration, section); `courseData.js` синхронизирован, выполнен `npm run build:config-meta`.
- [ ] Хук первого блока — ситуация из жизни подростка, не определение.
- [ ] Есть блок «Практика» с измеримым результатом ≤ 15 минут.
- [ ] Для math-уроков есть блок «Связь со школьной программой».
- [ ] Вопросы «Проверьте себя» покрывают главный тезис урока и согласованы с квизом
      `quizzes/quiz-{NN}.json`, если он существует.
- [ ] Все ссылки кликабельны и ведут на проверенные страницы.
- [ ] Объём 600–1200 слов; чтение укладывается в `lessonDuration`.
